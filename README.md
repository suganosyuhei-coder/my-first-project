# SHuTLe（シャトル）

React、Three.js、Rapier を組み合わせた、収集した製品を配置し、忘れられた文明の砂漠を探索する実験用アプリ。

## 開発

Node.js 22.12 以上（現在の環境: 24）で実行。

```sh
npm ci
npm run dev
```

```sh
npm run build
npm run preview
```

## 画面と操作

スタートから「全体モード」「図形のライブラリ」「砂漠へ冒険に出る」を選べます。全体モードと冒険は同じ地形・遺構・尖塔・配置物・収集地点を表示し、所持品を共有します。旧8図形パレットは撤去しました。

全体モードでは所持品を選び、地面をクリックして「＋ 配置」。配置物をクリックすると位置・回転・倍率・材質を編集できます。「回収」で所持品に戻ります。地面からの高さを負値にすると砂に埋まります。ドラッグで視点回転、ホイールでズーム。「全体表示」で広域を見渡し、ミニビュー操作でメインカメラを動かせます。

ライブラリの保存・読み込み、合体、Undo/Redo、ブラウザ再読み込み後の保存は未実装です。スクリーンショットは `artifacts/editor.png` と `artifacts/adventure.png`。開発予定は [TODO.md](TODO.md)。

## 無料のブラウザ公開（GitHub Pages）

公開先は GitHub Pages。`gh-pages` ブランチのルートにビルド結果を置きます。
GitHub の Settings → Pages → Build and deployment で Source を「Deploy from a branch」、Branch を「gh-pages」、フォルダーを「/ (root)」にして Save します。
公開URLは Pages 設定画面に表示されます。公開後も WebGL 対応ブラウザが必要です。
GitHub Free では公開リポジトリで Pages を利用できます。非公開の場合はプランにより制限があります。リポジトリの公開範囲はこの作業では変更しません。

更新時は `npm ci` と `npm run build` を実行し、`dist/` の内容を `gh-pages` ブランチへ反映します。ソースの更新だけでは公開サイトは更新されません。

## コード反映 → プレビュー → 微調整

変更をコミットした後、次のコマンドでソースと公開プレビューを更新します。

```sh
npm run deploy:preview
```

ビルド成功後、現在のコミットを `floating-workshop-preview` へ push し、ビルド結果を `gh-pages` へ push します。force push は使いません。公開プレビューを更新する際はこのコマンドを実行してください。ソースの push だけではプレビューは更新されません。
初回の Pages 設定は前述の手順が必要です。無料利用の条件はリポジトリの公開範囲とGitHubプランによります。

GitHub の Actions で Pages のデプロイ完了を確認し、公開URLで画面と操作を確認 → 調整内容を決める → 再度コードを修正・コミット・公開する、という流れです。
公開画面の上部にソースコミットの短縮IDを表示し、`version.json` に完全なIDを保存しています。更新が見えないときはデプロイ状況と表示IDを確認し、ブラウザを再読み込みしてください。

ソース変更の main へのマージは公開プレビュー更新とは別です。必要に応じて `floating-workshop-preview` から PR を作成します。

ロゴは添付された `src/assets/shutle_logo.svg` を使用。スタート画面では元のSVGの形状を維持して表示します。

## 冒険・収集

スタート画面の「砂漠へ冒険に出る」または編集画面の「冒険に出る」から開始します。

- WASD / 矢印で移動、Spaceでジャンプ。1単位=1m、重力1.62m/s²、ジャンプの上昇高さは約0.2m。Rapierキャラクターコントローラーの接地判定と上昇ロックで空中ジャンプを防止します。
- 右ドラッグで方向転換。一人称／三人称ボタンで視点を切り替えます。三人称では進行方向の背後から追従し、壁との間隔もレイで確認します。
- WASDは操作開始時のカメラ方向を基準にします。移動中にカメラが追従しても方向が勝手に回り続けないよう、同じキー操作中は移動の基準方向を保持します。
- 発光する星に触れると所持品が増え、星は消えます。獲得通知と短い粒子エフェクトを表示します。
- 所持品一覧から選び、「配置プレビュー」「前方に配置」で地面へ配置。「近くの物体を回収」で8m以内の物体を回収します。複数ある場合はクリックした物体を優先し、未選択なら最寄りを回収します。
- 配置は在庫1個を消費し、回収で1個戻します。在庫ゼロでは配置不可。全体モードと同じ所持品・配置データを使用します。
- 星は砂漠の4方向に40個。近距離・中距離・遠距離の出現比率は距離に応じて連続的に変わります。遠くでは相輪や大型水槽などが出やすくなります。
- 操作可能になってから、静止中も探索時間を計測します。Y < -12m、または開始位置からの水平距離170m超で終了。
- リトライで位置とタイマーをリセットし、所持品・配置物・収集済みの星は保持。編集／スタートへ戻っても保持します。ブラウザ再読み込み後の保存・復元は未実装です。

### データ・モデル

`src/data/materials.js`: 鉛・鉄・金・コンクリート・アルミニウム・樹脂の密度（kg/m³）と色・金属度・粗さ。製品の部品体積から重量を算出し、倍率の3乗と材質の変更を反映します。

`src/data/items.js`: 15種類の名称・アイコン・材質・初期在庫・寸法・構成部品・出現カテゴリを定義。重量は部品体積×材質密度の合計です。パイプの空洞を差し引きます。簡易モデルなので機器の重量は概算です。`initial`、`parts`、`LOOT_SETTINGS` を変更して種類や出現を調整できます。

`src/ItemModel.jsx`: 部品から既製品モデルを描画。外部モデル・画像の取得なし。金属の反射環境とコンクリートの粒状表面を生成します。

`src/Adventure.jsx`: 入力、キャラクター、背後カメラ、物理、収集、探索UI。星の接触と在庫操作は重複処理を防止。星は低ポリゴン、背景は点描画、反射環境64px、影1024px、描画解像度は最大1.5倍に制限しています。

アイテムは現在固定され、衝突は外寸の箱で近似します。中空部分を通り抜ける衝突、重量による動的挙動、自由飛行、無限生成は今後の拡張です。探索の最初の実験として浮遊通路を設け、歩行で遠距離の星に到達できるようにしています。


### 現在の砂漠・全体モード
スタート画面の「全体モード」で、初期所持品と冒険で集めた製品を配置します。地面をクリックして位置を指定し、「＋ 配置」で所持数を1減らします。配置物をクリックすると、位置・回転・倍率・材質を編集でき、「回収」で在庫に戻ります。「埋没 / 高さ」は地表からの相対高さで、負値で砂に埋まります。以前の8図形パレットと冒険専用の十字形道路は撤去しました。

全体・冒険で `DesertWorld` と同じ配置・所持品・星のデータを共有します。砂丘の描画メッシュとRapierの三角形衝突メッシュは同一データを使います。冒険ではRapierキャラクターコントローラーで砂丘を歩き、Spaceで約20cmジャンプします。右ドラッグで方向転換、ボタンで一人称/三人称を切り替えます。全体モードを挟んでも冒険の位置を保持し、探索半径170mを超えると探索終了になります。

黒い尖塔は北東の暗い砂地（約 X=52、Z=-48）に配置しています。環境に背景説明・敵・放射線ダメージはありません。所持品と配置は画面遷移中に保持しますが、ブラウザ再読み込みの保存と作品ライブラリは未実装です。大型配置物の衝突形状は外接直方体で近似しています。

検証: `npm test`（在庫・重量・出現率・ジャンプ・描画地形と物理地形・長距離砂丘歩行）、`npm run test:browser`（収集・配置・回収・全体/冒険共有）、`npm run test:exploration`（ジャンプ高さ・長距離探索・終了/再開）。
