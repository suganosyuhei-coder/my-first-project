# 浮遊工房 / Floating Workshop

React、Three.js、Rapier を組み合わせた、浮遊する足場を構築して歩く実験用アプリ。

## 開発

Node.js 22.12 以上（現在の環境: 24）で実行。

```sh
npm ci
npm run dev
```

```sh
npm run build
npm run preview
```

## 現在の仮画面

スタート画面から「図形のエディット」「図形のライブラリ」へ移動できます。
エディットは左側に8種類の回転するパーツ、右側に3D編集ビュー、右下に作品全体のミニビューを配置しています。

- パーツをクリックして選択し、X/Y/Zを入力して「追加」。ドラッグ＆ドロップは未実装です。
- メインビューはドラッグで視点回転、ホイールでズーム。「初期視点」で初期カメラへ戻ります。
- ミニビューは作品を表示します。メインビューとの操作連携は未実装です。
- スタートに戻っても編集中の作品は保持します。再読み込みすると初期化されます。
- ライブラリは案内画面のみ。保存・読み込み、合体は未実装です。
- 「歩行を試す」は初版の通常重力での歩行試作です。WASD / 矢印キーで移動、Spaceでジャンプ。落下・離脱時は作品を保持してスタートへ戻ります。
- スクリーンショットは artifacts/ に保存しています。

## 無料のブラウザ公開（GitHub Pages）

公開先は GitHub Pages。`gh-pages` ブランチのルートにビルド結果を置きます。
GitHub の Settings → Pages → Build and deployment で Source を「Deploy from a branch」、Branch を「gh-pages」、フォルダーを「/ (root)」にして Save します。
公開URLは Pages 設定画面に表示されます。公開後も WebGL 対応ブラウザが必要です。
GitHub Free では公開リポジトリで Pages を利用できます。非公開の場合はプランにより制限があります。リポジトリの公開範囲はこの作業では変更しません。

更新時は `npm ci` と `npm run build` を実行し、`dist/` の内容を `gh-pages` ブランチへ反映します。ソースの更新だけでは公開サイトは更新されません。
