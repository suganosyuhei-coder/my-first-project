## 補給型PAW（実装済み）

ユーザーは敵弾迎撃型ではなく「パーツ・水・修復」の補給型を選択した。

- 敵対PAWとは別の個体。自機へ接触ダメージを与えず、自機・ビット・ミサイルの攻撃対象にも含めない。
- 接触して補給が成立した時だけ、一度限りパーツ1個を自動追加し、水1個（VITAL＋8）を渡す。
- パーツ取得時の既存修復を利用し、最も損傷した箇所を8％、その上下を4％修復する。別途同じ修復を加算せず二重回復を防ぐ。
- パーツ候補は通常PAWと同じタンク・エンジン・射撃強化装置・パネル。緑PAWのパーツ候補にはミサイルを含めない。無限配管・固定センサーの仕様は維持する。通常PAWのミサイル搭載率は後続の頻度変更に従う。
- 補給成立時に yatta-06.jpg と「その見た目で、ちゃんと頼れるんだ。……やるね。」を出す。発見だけでは援護成功のセリフを出さない。
- 緑色の機体・明るい緑のバイザー・SUPPLY PAW表示で区別する。出現は約5,000m間隔（通常PAWの約1/5）。補給済みの個体は同一航行で復活せず、再挑戦で初期化する。

補給型の新設・出現頻度・接触ルールを実装した。
